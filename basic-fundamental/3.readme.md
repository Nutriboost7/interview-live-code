Basic Fundamental Coding - Problem 3

Title: Sum of Digits / Digital Root

Problem summary:
The digital root is the recursive sum of all the digits in a number. Given a non-negative integer n, repeatedly sum its digits until the result has only one digit. Return that single-digit result.

Details:
- Input: a non-negative integer n (n >= 0).
- Process: Sum the digits of n. If the sum has more than one digit, repeat the process until a single-digit number is produced.

Examples:

16     --> 1 + 6 = 7
942    --> 9 + 4 + 2 = 15 --> 1 + 5 = 6
132189 --> 1 + 3 + 2 + 1 + 8 + 9 = 24 --> 2 + 4 = 6
493193 --> 4 + 9 + 3 + 1 + 9 + 3 = 29 --> 2 + 9 = 11 --> 1 + 1 = 2

Constraints & hints:
- Straightforward approach: repeatedly split digits and sum; cost is proportional to the number of digits processed.
- Mathematical shortcut: for n > 0, digital root = 1 + ((n - 1) % 9). Handle n = 0 as a special case (result 0).

Testing suggestions:
- Test small numbers, large numbers, and edge cases like 0, 9, 10, 99, and large powers of ten.
