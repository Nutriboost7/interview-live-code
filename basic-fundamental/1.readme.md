# Problem 1 — Snail Sort (Spiral Order)

Difficulty: Easy — Fundamental

## Problem statement

Given an n x n 2D array (a square matrix), return a flat list of the matrix elements in clockwise spiral order (from the outermost layer inward).

Special case: an empty matrix is represented as `[[]]` and should return an empty list `[]`.

## Input / Output

- Input: `matrix` — list of `n` lists, each with `n` elements (integers or values).
- Output: list of values visited in clockwise spiral order.

## Examples

1) Example

```
matrix = [[1,2,3],
          [4,5,6],
          [7,8,9]]

output -> [1,2,3,6,9,8,7,4,5]
```

2) Illustration

```
matrix = [[1,2,3],
          [8,9,4],
          [7,6,5]]

output -> [1,2,3,4,5,6,7,8,9]
```

## Constraints & complexity

- Expected time complexity: O(n^2) for an n x n matrix (every element visited once).
- Expected extra space: O(1) beyond the output list (avoid unnecessary copies if possible).

## Hints

- Traverse layer by layer: top row (left→right), right column (top→bottom), bottom row (right→left), left column (bottom→top), then move to inner layer.
- Alternatively, simulate movement with direction vectors and mark visited cells or use boundary indices.
- Watch out for the center element when `n` is odd.

## Tests you should include

- `[[1]]` -> `[1]`
- `[[1,2],[3,4]]` -> `[1,2,4,3]`
- `[[ ]]` (empty) -> `[]`
- A 4x4 or 5x5 matrix to verify multiple layers.
