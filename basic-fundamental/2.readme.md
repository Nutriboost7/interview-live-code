Basic Fundamental Coding - Problem 2

Title: Stop gninnipS My sdroW! (reverse long words)

Problem summary:
Write a function that receives a string of one or more words. Return the same string but with every word of length 5 or more reversed. Words are separated by single spaces.

Details:
- Input: a string containing only letters and spaces.
- Words are separated by single spaces. There are no leading or trailing spaces.
- Only words with length >= 5 should be reversed; shorter words remain unchanged.

Examples:

"Hey fellow warriors"  --> "Hey wollef sroirraw"

"This is a test"       --> "This is a test"

"This is another test" --> "This is rehtona test"

Constraints & expectations:
- Time complexity: O(n) where n is the total length of the string.
- Space: O(1) additional (in-place) or O(n) if creating a new string.

Hints:
- Split the input by spaces, transform each word (reverse if length >= 5), then join back with spaces.
- Be careful with punctuation only if introduced (current spec has letters and spaces only).

Testing suggestions:
- Test words of lengths around the threshold (4,5,6), single-word input, and multiple words.
