# Problem 2 — Stop gninnipS My sdroW! (Reverse Long Words)

Difficulty: Easy

## Problem statement

Write a function that takes a string containing one or more words and returns the same string, but with every word of length 5 or more reversed. Words are separated by single spaces. Input contains only letters and spaces (no punctuation), and there are no leading or trailing spaces.

## Input / Output

- Input: a single string `s`.
- Output: a new string where every word with length >= 5 is reversed; shorter words remain unchanged.

## Examples

- `"Hey fellow warriors"`  -> `"Hey wollef sroirraw"`
- `"This is a test"`       -> `"This is a test"`
- `"This is another test"` -> `"This is rehtona test"`

## Constraints & complexity

- Time: O(n), where n is the length of the input string (each character is processed a constant number of times).
- Space: O(1) additional if you mutate in place (language permitting), otherwise O(n) for a new string.

## Hints

- Split the string into words, reverse words whose length >= 5, then join them back together with single spaces.
- If in-place mutation is required, iterate and reverse word ranges in the character buffer.

## Suggested tests

- `"Hello world"` -> `"olleH dlrow"` (both reversed)
- `"This is fun"` -> `"This is fun"` (no change)
- `"small words only"` -> correct handling of mixed lengths
- single-word edge cases: `"abcde"` (reverse), `"abcd"` (no reverse)
