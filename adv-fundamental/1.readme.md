# Problem 1 — Detect Pangram

Difficulty: Easy — Fundamental

## Problem statement

A pangram is a sentence that contains every single letter of the alphabet at least once. For example, the sentence "The quick brown fox jumps over the lazy dog" is a pangram, because it uses the letters A-Z at least once (case is irrelevant).

Given a string, detect whether or not it is a pangram. Return `True` if it is, `False` if not. Ignore numbers and punctuation.

## Input / Output

- Input: `s` — a string containing letters, numbers, spaces, and/or punctuation.
- Output: boolean — `True` if the string is a pangram, `False` otherwise.

## Examples

1) Example

```
s = "The quick brown fox jumps over the lazy dog"
output -> True
```

2) Example

```
s = "This is not a pangram"
output -> False
```

3) Example

```
s = "AbCdEfGhIjKlM zyx wpqr ston v"
output -> True
```

## Constraints & complexity

- Expected time complexity: O(n) where n is the length of the string (iterate through the string once).
- Expected space complexity: O(1) — at most 26 letters to track.
- Case insensitive — 'A' and 'a' are considered the same letter.
- Ignore all non-alphabetic characters (numbers, spaces, punctuation).

## Hints

- Convert the string to lowercase to handle case insensitivity.
- Use a set to track which letters have been seen.
- The English alphabet has 26 letters — check if all 26 are present.
- Alternatively, you can use the alphabet string "abcdefghijklmnopqrstuvwxyz" and check if each letter appears in the input string.

## Suggested tests

- Classic pangram: `"The quick brown fox jumps over the lazy dog"` -> `True`
- Missing one letter: `"abcdefghijklmnopqrstuvwxy"` -> `False`
- All letters present: `"abcdefghijklmnopqrstuvwxyz"` -> `True`
- With numbers and punctuation: `"1234 abc def!@# ghijk LMNOP qrs TUV wxyz"` -> `True`
- Empty string: `""` -> `False`
- Non-pangram sentence: `"Hello World"` -> `False`
- Mixed case: `"Pack my box with five dozen liquor jugs"` -> `True`
