# Problem 2 — Update Inventory in Your Smartphone Store

Difficulty: Easy — Fundamental

## Problem statement

You will be given an array which lists the current inventory of stock in your store and another array which lists the new inventory being delivered to your store today.

Your task is to write a function that returns the updated list of your current inventory in alphabetical order by brand name.

## Input / Output

- Input: 
  - `currentStock` — list of `[quantity, brand]` pairs representing current inventory.
  - `newStock` — list of `[quantity, brand]` pairs representing new deliveries.
- Output: list of `[quantity, brand]` pairs sorted alphabetically by brand name with updated quantities.

## Examples

1) Example

```
currentStock = [[25, 'HTC'], [1000, 'Nokia'], [50, 'Samsung'], [33, 'Sony'], [10, 'Apple']]
newStock = [[5, 'LG'], [10, 'Sony'], [4, 'Samsung'], [5, 'Apple']]

updateInventory(currentStock, newStock)  ==>
[[15, 'Apple'], [25, 'HTC'], [5, 'LG'], [1000, 'Nokia'], [54, 'Samsung'], [43, 'Sony']]
```

Explanation:
- Apple: 10 + 5 = 15
- HTC: 25 (no new stock)
- LG: 0 + 5 = 5 (new brand)
- Nokia: 1000 (no new stock)
- Samsung: 50 + 4 = 54
- Sony: 33 + 10 = 43

2) Example

```
currentStock = [[10, 'iPhone'], [20, 'Samsung']]
newStock = [[15, 'Samsung'], [5, 'Xiaomi']]

updateInventory(currentStock, newStock)  ==>
[[10, 'iPhone'], [35, 'Samsung'], [5, 'Xiaomi']]
```

## Constraints & complexity

- Expected time complexity: O(n log n) where n is the total number of unique brands (dominated by sorting).
- Expected space complexity: O(n) for storing the merged inventory.
- Brand names are case-sensitive.
- Quantities are non-negative integers.

## Hints

- Use a dictionary/map to track quantities by brand name.
- Iterate through current stock to populate the dictionary.
- Iterate through new stock to add/update quantities in the dictionary.
- Convert the dictionary back to a list of [quantity, brand] pairs.
- Sort the result alphabetically by brand name.
- Alternative: merge both lists, group by brand, sum quantities, then sort.

## Suggested tests

- Basic merge: brands in both lists should have quantities summed
- New brands: brands only in newStock should appear in output
- Existing brands: brands only in currentStock should remain unchanged
- Empty inputs: 
  - `currentStock = []`, `newStock = [[5, 'Apple']]` -> `[[5, 'Apple']]`
  - `currentStock = [[10, 'Apple']]`, `newStock = []` -> `[[10, 'Apple']]`
  - Both empty -> `[]`
- Alphabetical ordering: verify output is correctly sorted
- Multiple brands with similar names: test sorting accuracy
